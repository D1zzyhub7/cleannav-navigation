# EXP002 固定导航测试条件

## 实验目的
在不修改导航算法、局部代价地图频率和 Safety Lease 代码的前提下，固定当前仿真场景、地图数据库和目标，验证导航结果是否可重复。

## 固定条件
分支：ljy
Gazebo：ackermann_mcity_showcase_v2，GUI=false
RTAB-Map：cleannav_rtabmap_lidar.launch.py，使用现有 RTAB-Map 数据库
地图话题：/rtabmap/map
地图分辨率：0.05 m；本轮地图尺寸 261 x 189；地图原点约 (-1.319, -5.086)
局部代价地图：100 x 100，分辨率 0.05 m，范围约 (-2.45,-2.45) 到 (2.55,2.55)
全局代价地图：800 x 200，分辨率 0.05 m
初始 TF 检查：map 到 base_link 正常，首次记录约 (1.066,-0.492)
固定目标：map 坐标 (1.30,-0.49)，yaw=0；目标位于当前局部代价地图范围内
参数确认：local_costmap update_frequency 仍为 10.0 Hz，未修改算法参数

## 频率观测
测试期间 /local_costmap/costmap 实测平均约 1.67 Hz，最小间隔约 0.599 秒，最大间隔约 0.601 秒，标准差约 0.001 秒。

## 结果判断
三次导航均成功，成功率 3/3。三次起点接近但不是完全相同，原因是每次测试后机器人保持在上一目标附近；因此本轮证明了固定目标下的短距离导航可重复，但还不是严格重置仿真后的完全同起点对照。
本轮没有修改代码或参数，只新增实验记录。旧 EXP001 日志保持不变。

## 后续
若需要严格同起点统计，应在每次测试前重启 Gazebo、RTAB-Map 和导航，并重新确认同一 map 到 base_link 起点；本轮不将当前结果用于算法优劣比较。
